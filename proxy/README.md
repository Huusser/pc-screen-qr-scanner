# 本地 UA 代理：让桌面微信被识别为移动端

解决的具体问题：某些系统（如北森招聘门户）**按 User-Agent 分发两套前端包**，扫码登录后跳转的落地页路由只存在于移动包中，桌面微信打开就显示「页面不存在」。

本工具把**桌面微信内置浏览器**发出的请求，在到达服务器之前把 `User-Agent` 换成移动微信 UA。服务器据此下发移动包，落地页正常。

---

## 两种用法

### 推荐：交给桌面端按需启动（正常使用完全不受影响）

桌面扫码工具已经把它集成进去了，**你不需要手动开任何东西**：

1. 平时：代理进程根本不存在，系统代理设置一个字节都不动；
2. 扫到需要移动端的链接 → 结果条上出现「手机环境打开」→ 点它 → 弹卡问你要不要模拟手机；
3. 选「模拟手机微信」→ 才拉起本代理 → 打开链接 → 顶部胶囊显示倒计时；
4. 到点 / 点胶囊 / 关掉应用 → 自动停止并把系统代理还原。

> **关应用时如果代理还开着，会先弹窗确认**；确认后立刻还原系统代理再退出。
> 不存在"窗口关了、代理还在改系统代理"的状态。

### 万一断网了：双击 `restore-proxy-now.bat`

不用开主程序，双击就还原系统代理，然后告诉你结果。
只在"程序被任务管理器强杀、三层兜底都没赶上"这种极端情况下才需要。

### 手动：调试用（排查问题时才需要）

1. 双击 `start-proxy.bat`
   - 首次运行会生成并安装一张本地根证书（安装在「当前用户 → 受信任的根证书颁发机构」，不弹窗、不需管理员）
   - 自动把 Windows 系统代理指向本机代理（PAC 模式）
2. **完全退出微信，再重新打开**（微信只在启动时读取代理设置）
3. 正常操作：扫码 → 复制链接 → 文件传输助手 → 点开
4. 用完双击 `stop-proxy.bat` 还原系统代理

> 注意：桌面端启动时如果发现「没有活着的代理 + 上一轮残留的系统代理设置」，会静默还原。
> 所以手动 bat 起的代理不要和桌面端同时折腾。

想彻底移除证书：`uninstall-ca.bat`。

## 接管范围：默认只接管目标站

代码里**没有任何业务域名白名单**。判定只有一条：

> 请求头 `User-Agent` 同时包含 `MicroMessenger` 和桌面平台标记（`Windows NT` / `WindowsWechat` / `Macintosh` / `wechatMac`）→ 改写成移动微信 UA。

所以换成任何新系统都不用改代码。范围有两种模式：

| 模式 | 命令 | 说明 |
| --- | --- | --- |
| **收窄（桌面端默认）** | `--scope zhiye.com` | 只接管这些域（含子域），其余直连。桌面端按"要打开的那条链接"自动算出目标域，并连同父域一起传进来 |
| 全量（手动默认） | 不带 `--scope` | 任意链接都覆盖（排除腾讯系与系统更新域名） |

**收窄模式下怎么不漏掉跨站跳转**：扫码登录常常跨 3~4 个域
（`zhiye.com → appconnect.recruit.91paas.cn → open.weixin.qq.com`），
所以代理在**把 302 写回客户端之前**就解析 `Location`，把新域名同步推给
`/scope/add`（`mitm_proxy.learn` → `push_scope`）。等客户端拿到 302 去查 PAC 时，
范围已经更新过了 —— 这一点是收窄模式可用的前提，`_t_scope.py` 专门验它。

另外每个学习到的域名都会热更新 PAC 的**版本号**（`proxy.pac?v=N`）：
只改内容、URL 不变的话，Chromium/WinINET 很可能继续用缓存里的旧脚本。

管理接口（运行期可调）：

```
curl http://127.0.0.1:8899/status                 查看状态（含 proxy_all / scope_count）
curl http://127.0.0.1:8899/ua?mode=iphone         切换 UA（android 为默认，首选）
curl "http://127.0.0.1:8899/scope/add?host=a.com" 追加代理范围
curl http://127.0.0.1:8899/quit                   退出并还原
```

> 桌面端在「设置 → 代理范围」里选 **仅目标站**（默认）时传 `--scope`，
> 选 **全部站点** 或 **全局代理** 时不传（全局模式靠 `ProxyOverride`，做不了按域收窄）。
> 范围在界面状态条上可见："只接管 N 个域名，其余直连"。

> **历史**：2026-10-25 之前桌面端从不传 `--scope`，`proxy_all` 恒为 `true`，
> 而界面写着"PAC 只接管微信域名"——**文案与行为不符**。现已改为默认收窄，
> 并把文案统一成"仅目标站 / 全部站点"两种可选口径。

## 命令行参数

```
--mode android|iphone   移动 UA 选择，默认 android
--port <端口>           代理监听口，默认 8888
--admin-port <端口>     PAC / 管理接口，默认 8899
--scope a.com,b.com     只代理这些域（留空=全量）
--global-proxy          用传统全局代理代替 PAC（个别客户端不认 PAC 时用）
--no-system-proxy       不碰系统代理（自己用别的办法把流量导进来）
--no-ca-install         跳过证书安装
--restore               只还原系统代理（会从 8899 起扫 20 个口找活着的实例）
--remove-ca             卸载本地根证书
--parent-pid <PID>      拉起我的进程消失时自动收尾还原（防被强杀后残留）
--ttl <秒>              到点自动收尾还原，0=不限
```

端口被占用时，**桌面端**会自己往上顺延（最多 20 个）并把选中的端口传进来；
直接命令行跑则不会顺延，会明确报错：

```
[error] 端口 8888 已被其他程序占用（Fiddler / Charles 等调试代理常用 8888）…
```

桌面端就是用下面这组参数起它的（端口是现挑的，这里写实际值）：

```
python run_proxy.py --mode android --port 8889 --admin-port 8900 \
                    --parent-pid <Electron 主进程 PID> --ttl 180
```

这样即使桌面端崩了、被任务管理器强杀，python 也会在 0.5 秒内发现父进程消失，
自己停掉代理并把系统代理还原——不会把用户机器留在"全局走代理"的状态。

## 安全边界

| 做了什么 | 没做什么 |
| --- | --- |
| 只改请求头 `User-Agent` | 不改请求体、响应体、Cookie、任何业务数据 |
| 只对「桌面微信」流量改写 | 普通浏览器 / 微信自身 API 原样透传 |
| 证书只装在当前用户下 | 不装系统级、不需要管理员、不动系统证书库其他内容 |
| 日志只记域名与改写计数 | 不记录 URL 参数、不落盘任何页面内容、不上传 |
| 腾讯系域名直接 TCP 隧道 | 不解密，避免影响微信登录与快速登录通道（14013） |
| 证书装不上就停手（退出码 4） | 不把系统代理指到本地代理、不谎报"已启动" |

## 常见问题

**1. 微信里打开还是桌面版（没生效）**
微信在启动时读取代理设置。**完全退出微信**（托盘右键退出，确认任务管理器里没有 `Weixin.exe`）再打开。
仍不生效 → 换 `start-proxy.bat --global-proxy` 用传统全局代理，部分客户端不认 PAC。

**2. 微信里页面提示证书错误**
说明微信不信任本机根证书。检查 `start-proxy.bat` 输出里是否有 `[ca] OK INSTALLED` 或 `[ca] OK ALREADY`；
可手动运行 `uninstall-ca.bat` 后再重新 `start-proxy.bat`。

**2.1 提示"根证书未能安装"**
现在证书装不上会**直接停手**，不会把系统代理指过来：

```
[ca] 失败，停止启动 —— 安装脚本执行失败：...
[exit] 已停止（未设置系统代理）
```

常见原因：企业组策略禁止写「受信任的根证书颁发机构」、安全软件拦截 PowerShell、`install-ca.ps1` 被隔离。
这个提示会同时写进 `last_exit.json`，桌面端直接显示同一句话。排查完重新点一次「手机环境」即可。
装完还会**回查**一次（`install-ca.ps1 -Verify`，只读）；如果证书被安全软件回滚，同样按失败处理。

**2.2 非 443 端口的 HTTPS（8443 / 9443 等）**
上游那一条腿现在由调用方声明是否 TLS（`connect_upstream(..., tls=True)`），不再按端口号猜，
所以 443 以外的 HTTPS 后台也能正常走代理。此前这类地址会稳定 502。

**2.3 提示"端口 8888 已被其他程序占用"**
说明 Fiddler / Charles / 其它调试代理正占着 8888。桌面端点「手机环境」时会自动顺延端口，
不用处理；直接命令行跑的话加 `--port 8889`（管理口也一起换：`--admin-port 8890`）。
注意 Windows 上 `SO_REUSEADDR` 语义特殊，**两个进程能同时监听同一端口**，
所以这个判断是靠"自己能不能绑"（`port_busy()`）而不是"能不能连上"。

**3. 影响我正常上网吗**
默认只接管你要打开的那个站（连父域），其余流量完全不经代理，所以影响面比看上去小。
用完 `stop-proxy.bat` 即完全还原。想让所有站点都走代理（比如手工排查），启动时加
`--scope` 之外的参数组合里没有开关，直接不带 `--scope` 就是全量。

**3.1 页面还是 PC 版 / 仍是 404**
先看 `/status` 的 `proxy_all` 与 `scope`：收窄模式下目标域应该在列表里。
如果目标域在、但下一个跳转过来的域不在，说明那次跳转没被学习到（例如 JS 跳转、或站点用
`window.location` 而不是 302）。临时办法：把范围改成全部站点，或手动
`curl "http://127.0.0.1:8899/scope/add?host=那个域名"`。

**4. 安全软件报警**
"装根证书 + 改系统代理"与抓包工具行为一致，属正常告警。可加白名单；代码全部是本目录下的明文 Python，可自行审阅。
默认范围收窄后，被解密的流量只有目标站与它跳转到的几个域。

**5. 页面能打开，但还是 404**
UA 已生效但该站点的移动包本身也没有这条路由（少数系统对移动端另有要求，比如必须在手机端微信里才放行）。此时 UA 伪装已到极限，改走"推动业务方开 PC 入口"。

## 文件说明

```
start-proxy.bat    启动（首次会自动装证书）
stop-proxy.bat     停止并还原系统代理
uninstall-ca.bat   卸载本地根证书
restore-proxy-now.bat 断网急救：只还原系统代理（不需要能上网）
python-env.bat     被上面几个 bat 调用：按顺序找 Python，找不到就说清找过哪些位置
run_proxy.py       管理器：PAC / 管理接口 / 系统代理设置与还原
mitm_proxy.py      代理本体：TLS 解密 + UA 改写 + 隧道 + 跳转域学习
certgen.py         纯标准库的 RSA 密钥生成 + X.509 证书签发（不再依赖 openssl）
certs.py           证书管理：默认用 certgen 现场签发本地 CA 与按域名证书
install-ca.ps1     安装/卸载证书（当前用户，静默）；`-Verify` 只读回查"在不在库里"
certs/             生成的证书（ca.crt 为根证书）
_t_*.py            测试脚本（`_t_ca_guard.py` 证书失败停手、`_t_port_guard.py` 端口被占、
                   `_t_scope.py` 范围收窄与 302 同步学习、`_t_proxy_mitm.py` 非 443 TLS 等），
                   不进安装包
```

依赖：**只有 Python 3.8+，不依赖 openssl，也没有第三方库**（自 0.4.0 起）。

- 证书签发原本调 `openssl` 命令行，现已改为纯 Python 实现（`certgen.py`），
  原因是 Windows 不自带 openssl，公开发布时要求用户装 Git 等于砍掉「手机环境」。
- 想退回旧实现排查用：`QRSCAN_CERT_BACKEND=openssl`（需本机有 openssl）。
- 桌面端发行包自带 Python 运行时（`desktop/vendor/python`），用户机器上不需要装任何东西。
- 几个 `.bat` **都不再写死解释器路径**（此前写的是开发机上的绝对路径，换台机器必失败）。
  查找顺序：`QRSCAN_PYTHON` → 内置运行时（源码树 `..\desktop\vendor\python`，
  安装后 `..\app.asar.unpacked\vendor\python`）→ `py -3` → `python`。
  想强制指定就 `set QRSCAN_PYTHON=D:\Python312\python.exe` 再双击 bat。
- 本文件（`README.md`）**不进安装包**：它给仓库读者看，安装目录里没有意义。
